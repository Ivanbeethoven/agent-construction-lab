# 项目接手记录

接手日期：2026-10-23（Asia/Shanghai）。本记录基于所提供的本地目录、原 ZIP、原始 README、测试代码、manifest 和保存的运行结果；没有执行真实模型调用，也没有重新检索或核验缺失的文献目录。

## 研究定位

核心问题是：固定基础模型 M，通过源任务中的成对编辑经验，在目标任务执行之前选择 agent harness，是否能改善部署表现；之后再进行相同预算的反馈优化 R，还能带来多少增益。

原说明的七条件是 G、D、S、V、F、G+R、F+R。关键比较分别为普通构建与配对编辑学习、最终价值预测 V 与编辑效果预测 F、以及 G/F 两种起点下反馈优化的增量。需要共同约束模型身份、候选空间、数据角色、执行种子、优化预算和成本口径。

`tests/` 已有对数据隔离、query 前冻结、同族复用、源成本去重、HTTP 用量、GEPA 预算、AppWorld 子进程和语法策略的断言。但测试所引用的实现大部分不在交付中，不能仅凭测试存在就认定机制已经有效实现。
