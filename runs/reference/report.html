07 / 解释边界与复现依据

这次运行证明了哪些链路

  1. 机制真实执行。 环境有状态、工具调用、超时后的已提交副作用、重复写入、worker 重启与恢复事件；retry、幂等、checkpoint、schema adapter 改变可执行 harness 行为。执行者是有限状态 actor。
  2. 构建阶段只看公共规格。 实际故障是否发生与发生位置在执行时由任务身份和隐藏执行种子确定；公共风险类别仍是较强信息，规则控制因此必须保留。
  3. 隔离的是任务身份和监督角色。 源 / dev / test 的 family 名称不重叠，但都共享同一事务生成器；这不是跨真实领域泛化。支持集按公开接口能力预先选择，query 保留接口受限任务和未见组合。
  4. Query 不参与优化。 source-only 训练、支持集候选评估、最终冻结 artifact 的 query 评估分别记录。失败执行计入分母；没有按效果剔除任务或方法。
  5. 冻结可被核验，但不保证语义正确。 agent 源码、manifest 与依赖摘要提供相对于可信外部 digest 的篡改检测；静态语法和接口检查不等于行为正确性、代码沙箱或数字签名。
